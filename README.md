# A Numerical Comparison of Two Discrete Models of Surface Bending

Welcome to this project repo!

This is a study on two discrete models of surface bending:

1. Flat Domain Hessian Energy Model (IBM)
2. Isometric Bending Model (FDHE)

Particularly, convergence of force density and mean curvature are studied along with the time complexity for constructing the discretization schemes. The broader goal of the project is to evaluate whether, particularly the IBM, is a feasible model for applications within bending of fluid membranes.
